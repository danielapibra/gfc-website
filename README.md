# Golden Fight Club

Sitio web de Golden Fight Club, gimnasio de boxeo y acondicionamiento
físico en Duitama, Boyacá.

Publicado con GitHub Pages directamente desde la rama `main` — sin paso de
build, sin dependencias.

## Ver localmente

```
python3 -m http.server 8000
```

Luego abrir `http://localhost:8000`.

## Estructura

```
index.html
assets/
  css/styles.css
  js/script.js
  img/
  video/
```

## Secciones

Hero (con reloj de round y estado abierto/cerrado en vivo), Nosotros
(historia + carrusel de fotos y video), Horarios, Planes (con precios
reales), Equipo, Galería, Eventos, Reseñas, Ubicación.
